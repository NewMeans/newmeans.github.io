# Changes to the Privacy Policy

Effective date: 2026-11-25

What changed: With the introduction of usage analytics and error recording tools (Google Analytics for Firebase, Firebase Crashlytics) in the Game for Android, the following was added.

- Purposes of processing: analyzing Game usage statistics, finding and fixing errors, and measuring the performance of ads that promote the Game
- Items processed: app instance ID and installation ID created by the analytics tool, Game usage records, error records, device model and operating system, app version, language setting, country and region estimated from the IP address, advertising identifier
- Retention periods: Game usage records 14 months, error records 90 days
- Entrustment and transfer abroad: Google LLC (United States)
- The payment tool (RevenueCat) passes confirmed purchase details and the anonymous user ID to the analytics tool.

Why: To find and fix errors in the Game and to improve the Game using usage statistics.
